# Mineru Integration Guide\n\n## Overview\n\nThis document describes the Phase 3 implementation of Mineru API integration for PDF parsing and citation extraction in the literature management system.\n\n## Architecture\n\n### New Components\n\n1. **MineruService** (`src/libs/parsing/MineruService.ts`)\n   - Handles async PDF submission to Mineru API\n   - Manages task polling and result retrieval\n   - Processes ZIP files containing parsed data\n\n2. **Enhanced LibraryService** (`src/libs/db/LibraryService.ts`)\n   - Integrated Mineru workflow into background processing\n   - Added new parsing status states\n   - Implements non-blocking citation processing\n\n3. **Updated Data Models** (`src/libs/db/schema.ts`)\n   - Extended ParsingStatus enum with Mineru-specific states\n   - Added `mineruTaskId` field for tracking API tasks\n\n## Workflow\n\n### Complete Processing Pipeline\n\n```\n1. User creates item → createFromMetadata()\n2. PENDING_PDF_FETCH → PDF fetcher attempts download\n3. PENDING_MINERU_SUBMISSION → Submit PDF to Mineru API\n4. PARSING_IN_MINERU → Wait for Mineru processing\n5. SUCCESS → Citations extracted and linked\n```\n\n### Status States\n\n- `IDLE` - Initial state\n- `PENDING_PDF_FETCH` - Fetching PDF from DOI/URL\n- `PENDING_MINERU_SUBMISSION` - About to submit to Mineru\n- `PARSING_IN_MINERU` - Waiting for Mineru processing\n- `SUCCESS` - Processing completed successfully\n- `FAILED` - PDF fetch failed\n- `PARSING_FAILED` - Mineru processing failed\n- `AWAITING_MANUAL_UPLOAD` - No PDF source, manual upload needed\n\n## Configuration\n\n### Environment Variables\n\n```bash\n# Required: Your Mineru API token\nMINERU_API_TOKEN=your-actual-api-token\n\n# Required: Mineru API base URL\nMINERU_BASE_URL=https://api.mineru.com/v1\n```\n\n### Configuration File\n\nSee `src/libs/parsing/config.ts` for detailed configuration options:\n\n```typescript\ninterface MineruConfig {\n  apiToken: string;\n  baseUrl: string;\n  pollInterval: number; // 5000ms default\n  maxPollTimeout: number; // 30 minutes default\n}\n```\n\n## Usage Examples\n\n### Basic Usage\n\n```typescript\nimport { libraryService } from './libs/db/LibraryService';\n\n// Create item with DOI - automatically triggers full pipeline\nconst itemId = await libraryService.createFromMetadata({\n  title: 'Machine Learning Paper',\n  authors: ['John Doe'],\n  year: 2024,\n  doi: '10.1038/nature12373'\n});\n\n// Returns immediately, processing continues in background\nconsole.log('Item created:', itemId);\n```\n\n### Monitoring Processing Status\n\n```typescript\n// Check processing status\nconst item = await libraryService.getLibraryItemById(itemId);\nconsole.log('Status:', item.parsingStatus);\nconsole.log('Task ID:', item.mineruTaskId);\n```\n\n### Direct Service Usage\n\n```typescript\nimport { mineruService } from './libs/parsing';\n\n// Submit PDF directly to Mineru\nconst taskId = await mineruService.submitTaskFromFile(item, pdfBlob);\n\n// Poll for results\nconst results = await mineruService.pollTaskResult(taskId);\n```\n\n## Database Schema Updates\n\n### Version 3 Changes\n\n```sql\n-- Added mineruTaskId field to library table\nALTER TABLE library ADD COLUMN mineruTaskId TEXT;\n\n-- Updated parsingStatus enum with new states\n-- PENDING_MINERU_SUBMISSION, PARSING_IN_MINERU, PARSING_FAILED\n```\n\n## Error Handling\n\n### Common Error Scenarios\n\n1. **API Configuration Issues**\n   - Missing or invalid API token\n   - Incorrect base URL\n   - Result: Status remains `PENDING_MINERU_SUBMISSION`\n\n2. **Network/API Errors**\n   - Connection timeouts\n   - API rate limits\n   - Server errors\n   - Result: Status changes to `PARSING_FAILED`\n\n3. **Processing Failures**\n   - Invalid PDF format\n   - Corrupted files\n   - Unsupported content\n   - Result: Status changes to `PARSING_FAILED`\n\n### Error Recovery\n\n```typescript\n// Retry failed processing\nif (item.parsingStatus === 'PARSING_FAILED') {\n  await libraryService.updateParsingStatus(itemId, 'PENDING_MINERU_SUBMISSION');\n  // Manually trigger reprocessing if needed\n}\n```\n\n## Performance Considerations\n\n1. **Non-blocking Operations**\n   - All processing happens in background\n   - UI remains responsive\n   - Multiple items can be processed concurrently\n\n2. **Resource Management**\n   - Configurable polling intervals\n   - Automatic timeout handling\n   - Memory-efficient ZIP processing\n\n3. **API Rate Limiting**\n   - Default 5-second polling interval\n   - Configurable timeouts\n   - Graceful error handling\n\n## Testing\n\n### Development Testing\n\n```typescript\n// Run the example workflow\nimport { demonstrateMineruWorkflow } from './libs/db/mineru-workflow-example';\n\nawait demonstrateMineruWorkflow();\n```\n\n### Unit Testing\n\n```typescript\n// Test individual components\nimport { mineruService } from './libs/parsing';\n\n// Test configuration\nconst config = mineruService.getProviderInfo();\nconsole.log('Provider:', config.name, config.version);\n```\n\n## Migration Guide\n\n### From Phase 2 to Phase 3\n\n1. **Database Migration**\n   ```typescript\n   // Database automatically migrates to version 3\n   // No manual intervention required\n   ```\n\n2. **Code Updates**\n   -
